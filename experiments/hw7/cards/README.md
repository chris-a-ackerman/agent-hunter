# Agent cards for HW7 card-variant experiments (AGE-62, AGE-63)

`original/` holds the 7 public agent cards exactly as frozen at
`agent-hunter-providers@5d9536a` (PREREG §12), copied with
`git show 5d9536a:providers/<slug>/card.json`. Do not edit them.

These are the only provider files the AGE-62 / AGE-63 work needs. Per PREREG §13 and AGE-63's
fairness rules, that work must not read `agent-hunter-providers/` (it holds the private traits).
Card variants go next to `original/` (e.g. `inflated/`, `price_shuffled/`) and are generated
mechanically by a committed script.

## Variants (AGE-63)

`inflated/` and `price_shuffled/` are generated by `experiments/hw7/card_variants.py`
(`uv run python -m experiments.hw7.card_variants`). The script reads `original/` only and
writes the same 7 slugs into each variant. No wording is written by hand. Running it twice gives
byte-identical files, and a test checks the committed files against the script's output. The
committed files are the freeze: no live run uses them before they're merged. Don't edit them by
hand.

- `inflated/`: each card keeps its slug, name, version, job types, price and region. Its
  `description` is replaced, word for word, by Quillbase's description (`original/quillbase.json`).
  Quillbase's own card is unchanged.
- `price_shuffled/`: each card is unchanged except `price_per_doc_usd`. The 7 original prices,
  taken from the slug-sorted cards, are permuted with `random.Random(0).shuffle` (seed 0) and
  given back in slug order. The prices are the same set as in `original/`.

  The seed-0 shuffle gives:

  | slug | original price | shuffled price |
  | -- | -- | -- |
  | docuvant | 0.02 | 0.06 |
  | northledger | 0.04 | 0.025 |
  | paperlark | 0.025 | 0.04 |
  | parsewell | 0.015 | 0.02 |
  | quillbase | 0.06 | 0.002 |
  | tallyforge | 0.002 | 0.015 |
  | veridex | 0.03 | 0.03 |

  Quillbase does **not** keep the highest price: it gets the lowest (0.002), and Docuvant gets
  the highest (0.06). Veridex keeps its own price. The shuffle was run once and kept, not
  re-rolled.
