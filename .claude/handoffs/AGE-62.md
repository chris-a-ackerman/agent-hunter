## Assumptions
- "Ties broken by slug" means the alphabetically first slug wins, the same as `pick_cheapest`.
- The new row goes last in each split (after Random), so the existing rows stay in place in the diff.
- `analyse()` raises `AnalysisError` if the most-expensive card's provider has no held-out answers for a job,
  so a missing price pick can't pass silently. `analyse_job(job)` without `most_expensive` leaves the method
  out, and `main_rows` / the report skip methods that have no picks.
- Added a `--cards-dir` CLI option (default `cards/original/`) so the tests can point at fixture cards. The
  regeneration commands from the issue still use the default.
- The charts don't get a most-expensive line. The PNGs regenerated byte-identical and aren't in the diff.
